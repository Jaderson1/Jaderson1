## 🧬 Minha evolução

Comecei escrevendo meus primeiros scripts em Python, sem entender muito bem o que estava fazendo.

Depois descobri o **FastAPI** e passei a construir APIs de verdade — e daí não parei mais.

No caminho fui absorvendo **React, TypeScript, Docker, Terraform e Ansible**, sempre aprendendo através de projetos e problemas reais.

Hoje atuo como desenvolvedor Full Stack, construindo **APIs geoespaciais na Itaipu Parquetec** e desenvolvendo o **Fluida**, um projeto open-source para React e Dash.
