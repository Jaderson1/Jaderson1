## Projetos

### Fluida
Motor de layout adaptativo, open-source e agnóstico de framework, para React e Dash.
O core é escrito em TypeScript sem dependência de framework, com bindings específicos
para cada alvo, distribuídos como pacotes separados em um monorepo.

`TypeScript` · `React` · `Dash` · `monorepo`

[Ver projeto](https://github.com/Jaderson1/fluida) · em desenvolvimento

### Plataforma de monitoramento ambiental
Aplicação Dash + FastAPI para acompanhamento de programas de logística reversa.
Consultas espaciais em PostGIS, cache em Redis e autenticação centralizada via
Keycloak, com segredos gerenciados no Vault.

`Python` · `FastAPI` · `Dash` · `PostGIS` · `Redis` · `Keycloak`

### Automação de relatórios mensais
Pipeline que gera os relatórios operacionais mensais de um programa de coleta de
eletroeletrônicos. Monta os documentos .docx com layout de tabela controlado via XML,
exporta em PDF e sincroniza a saída com o armazenamento em nuvem.
Logging estruturado com structlog — console colorido em desenvolvimento, JSON em produção.

`Python` · `python-docx` · `structlog` · `rclone`
